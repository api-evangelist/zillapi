# Zillapi

Independent third-party provider of Zillow-sourced U.S. residential property data via a REST API, hosted MCP server, and agent skills. Returns ~300+ fields per property including price, Zestimate, rent Zestimate, photos, schools, taxes, and full price history, plus listing search, building extraction, async batch jobs, and signed webhooks.

- **Provider:** https://zillapi.com
- **Documentation:** https://zillapi.com/quickstart/
- **Base URL:** https://api.zillapi.com

## APIs

- **Zillapi Property Data API** — REST API returning Zillow-sourced U.S. residential property data with bearer auth, plus a hosted MCP server, llms.txt, and published agent skills. (`https://api.zillapi.com`)

> REST API host is https://api.zillapi.com (zillapi.com root is marketing/docs). OpenAPI 3.1 at /openapi.json is public. Hosted MCP server at https://api.zillapi.com/mcp (streamable-http, four tools: lookup_property_by_address, lookup_property_by_zpid, get_zestimate, search_listings; bearer or OAuth 2.1). MCP discovery card at https://zillapi.com/.well-known/mcp/server-card.json. Agent skills also distributed via npx from github.com/ZeroPointRepo/zillow-skills. No AsyncAPI, GraphQL, or public Postman collection found; webhooks are HMAC-SHA256 signed callbacks. Also present: /.well-known/api-catalog and /.well-known/ai-plugin.json.
